# Instrucciones del ejemplo

- Usar JavaScript moderno sin dependencias externas.
- Mantener compatibilidad con Node.js 22.
- No modificar fuera de `../02-docker-compose/backend/` salvo pedido explícito.
- Responder con JSON excepto en `/metrics`.
- Verificar con `node --check server.mjs`.
- Resumir archivos modificados y verificaciones ejecutadas.
