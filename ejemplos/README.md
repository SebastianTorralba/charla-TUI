# Ejemplos del workshop

Cada carpeta acompaña una guía:

- `01-terminal`: archivos para nano, Neovim, Midnight Commander y tmux.
- `02-docker-compose`: frontend, backend y PostgreSQL.
- `03-observabilidad`: Prometheus y Grafana.
- `04-codex`: `AGENTS.md` y consignas de práctica.
- `05-remoto`: plantillas para SSH y SFTP.

Consultá el `README.md` de cada carpeta antes de comenzar.
