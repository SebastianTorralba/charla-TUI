# Práctica de Codex

```bash
cd ejemplos/04-codex
codex
```

Pegá, en orden, las consignas guardadas en `prompts/`: primero comprender, después planificar prioridades, luego implementar y por último revisar. El código objetivo está en `../02-docker-compose/backend/`.

El skill local de demostración está en `.agents/skills/validar-funcionalidad/SKILL.md`. Si no aparece en `/skills`, reiniciá Codex.

> El backend actual es deliberadamente mínimo y no implementa un gestor de tareas. El requerimiento sirve para practicar cómo Codex detecta contexto faltante y propone un plan antes de modificar. Para una demo completa, adaptalo al backend de tareas elegido para el workshop.
